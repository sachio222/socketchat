Not everyone wants to set up a server. A ready-made Socketchat server you can buy from [socketchat.org](https://socketchat.org) is on its way.

You will get a server that is already running, with an address your friends can reach from anywhere. You install Socketchat, use your first invite, and start a room. Your messages stay end-to-end encrypted the same way they are on a server you run yourself: the server passes them along and cannot open them.

Until then, any of the [ways to host](/hosting/overview) gets you running today. A [cloud server](/hosting/cloud-server) is the closest match: always on and reachable from anywhere.

Watch [socketchat.org](https://socketchat.org) for news.
