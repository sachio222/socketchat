## Slash commands

Type these in the chat screen's message box. Tab completes a command as you type it, and after `/switch`, `/invite` or `/join` it puts in a room or a name; Up and Down step through the same list. See [Complete rooms and names](/use/chat-screen#complete-rooms-and-names). `/help`, or `/` and Enter, lists every command in alphabetical order to pick from; see [Find a command](/use/chat-screen#find-a-command).

### Rooms and people

| Command | What it does |
|---|---|
| `/new <name>` | Start a new group chat on the open room's server, and say which server. |
| `/invite` | Make a one-time link that brings someone into this chat, and copy an invite message. |
| `/invite --dm` | Make a link that opens a new two-person chat. |
| `/invite <name> [room]` | Invite someone you already share a room with to this room, or to the room you name. Tab completes the name. See [Invite someone you share a room with](/use/rooms-and-invites#invite-someone-you-share-a-room-with). |
| `/join <link>` | Use an invite link someone sent you. |
| `/join <room>` | Join a room someone invited you to by name. Tab completes the room. `/join` alone joins when one invite waits. |
| `/join <number>` | Join one of several invites that fit, by the number `/join` listed. |
| `/dm <name>` | Start a two-person chat with someone in this chat. |
| `/switch [room]` | Open another room. Tab, or Up and Down, step through the room names; with no name, opens the switcher. |
| `/verify <name>` | Compare safety numbers with someone. |
| `/name <new>` | Change the name others see for you. |
| `/rename <name> <new>` | Rename someone on your screen only. |
| `/invites` | See your open invite links. |
| `/cancel <number>` | Stop an invite link from the `/invites` list. |
| `/details` | See this room's admins, size, age, server, topic, settings and encryption. |
| `/topic [text]` | See the room's topic, or set it. `/topic --clear` removes it. Admins only, unless the room lets anyone set it. |
| `/settings` | See who can invite, whether slow mode is on and who can set the topic. |
| `/mute` | Hide this room's new-message count. |
| `/unmute` | Show this room's new-message count again. |
| `/leave` | Leave this chat and delete its history here. |
| `/clear` | Delete this room's messages from this computer. |

### Admins

| Command | What it does |
|---|---|
| `/kick <name>` | Remove someone. |
| `/admin <name>` | Make someone an admin. |
| `/title <name>` | Rename this room for everyone. |
| `/settings invite admins\|anyone` | Choose who can bring people into this room. Rooms start with anyone. |
| `/settings slow <seconds>\|off` | Make each member who isn't an admin wait between messages, up to 6 hours, or turn that off. |
| `/settings topic anyone\|admins` | Choose who can set this room's topic. Rooms start with admins. |
| `/close` | Close this room for everyone, once the admins agree. |
| `/keep` | Say no to closing this room. |

Room settings need a server on 0.5.2 or later, and everyone in the room on 0.5.2 or later. See [Room settings](/use/rooms-and-invites#room-settings).

### Files

| Command | What it does |
|---|---|
| `/send <path>` | Send a file, photo or video. Dropping the file on the window does the same; see [Drop a file on the window](/use/files-photos-videos#drop-a-file-on-the-window). |
| `/save <file> [folder]` | Save a file someone sent. Use `<file>:<number>` when several files share a name. |

### Servers

| Command | What it does |
|---|---|
| `/servers` | List every server your profile knows, numbered, with how many of your rooms are on each and whether it is connected, could not be reached and why, or not connected yet. |
| `/forget <number>` | Delete a server from the `/servers` list, with its rooms, from this computer. Asks first. |

`/forget` deletes that server's rooms, their messages and keys, the joins waiting there, the invite links you made there, its certificate and your account key, all from this computer only. The server is not told, so others there still see you in its rooms until an admin removes you. If the server still works, `/leave` its rooms first. Run `/servers` before `/forget`, because `/forget` takes a number from the last list it showed.

New rooms go on the open room's server. With no room open, they go on the newest server you joined. `/new` says which one, as in "Made Book club on chat.example.com.", and `/servers` marks that server "(new rooms go here)".

### The app

| Command | What it does |
|---|---|
| `/theme [name]` | See or change the colors: `phosphor` or `classic`. |
| `/mouse [on\|off]` | Turn mouse clicks, scrolling and drag to copy on or off. |
| `/updates [on\|off]` | Turn the daily check for a new version on or off. See [Updating](/help/updating#the-update-notice). |
| `/status` | See the open room's server and connection, you, the room and the app in one box. See [`/status`](#status). |
| `/help` | List every command in alphabetical order, and pick one to use. |
| `/about` | See the version, what Socketchat is and what the server still sees. |
| `/quit` | Close Socketchat at once. Ctrl-C twice within 2 seconds does the same. |

A name with spaces goes in quotes, as in `/save "beach day.jpg"` or `/invite Bo "Climbing Saturdays"`.

### `/status`

`/status` opens one box with what Socketchat knows about the open room and its server:

- **Server**: its address and port, whether Socketchat is connected and since when, the protocol in use, the certificate fingerprint your app trusts for that server, and the server's rule on inviting into rooms. Servers do not tell apps their Socketchat version, so the box shows the protocol instead.
- **You**: your name, your half of each safety number, and how many of your rooms are on that server.
- **Room**: its kind, members and how many of them you verified, admins, your role, settings, whether it has a topic, and its encryption with the suite's name and number.
- **App**: the version, the update check and the newest release it last found, the theme and the mouse setting.

A last line points to `/details` for what the server can see. The box scrolls, and dragging over its text copies it. To check that you reach the right server, compare the fingerprint with the one its operator's `socketchat server init` printed.

## Terminal commands

Run these in a terminal. `socketchat --help` and `socketchat <command> --help` print the same list.

| Command | What it does |
|---|---|
| `socketchat` | Open the chat screen. With no profile yet, print how to start. |
| `socketchat join <link> [--new-certificate]` | Use an invite link. The first time, this also sets up your profile. Opens the chat screen when run in a terminal. |
| `socketchat new <name> [--server <number>]` | Start a new group chat on the newest server you joined, or on the server at that number in `socketchat servers`. |
| `socketchat servers [--forget <number>] [--yes]` | List your servers and whether each can be reached, or forget one. `--yes` forgets without asking first. |
| `socketchat invite --group <name>` | Print an invite link to a room, on one line. |
| `socketchat invite --dm` | Print a link that opens a new two-person chat. |
| `socketchat invite --group <room> <name>` | Invite someone you already share another room with into that room, by name. They take it with `/join` in the chat screen. |
| `socketchat invites [--cancel <number>]` | List your open invite links, or cancel one. |
| `socketchat send --group <name> <text>...` | Send a message to a room. When the room limits fast posting, waits until the message goes. |
| `socketchat topic --group <name> [<text>...] [--clear]` | Print a room's topic, set it with text, or remove it with `--clear`. |
| `socketchat log --group <name> [--limit <n>]` | Print a room's recent messages, 50 by default, and mark them read. When more are unread than the limit, prints the oldest unread first. |
| `socketchat sync` | Fetch everything new and print what happened, including a line when someone invites you by name. |
| `socketchat status [--group <name>]` | Print the server, the connection, your name and the app's settings, one fact a line, as `/status` shows them. `--group` adds a room. |
| `socketchat server init [--host <address>] [--listen <ip:port>] [--data-dir <folder>]` | Set up a server. See [Server settings](/hosting/server-settings). |
| `socketchat server run [--data-dir <folder>] [--config <file>]` | Run the server until Ctrl-C. |
| `socketchat server invite [--data-dir <folder>]` | Print a one-time link that registers a new person on this server. |
| `socketchat update` | Print the command that installs the newest release, for the way this copy was installed. It installs nothing. See [Updating](/help/updating). |
| `socketchat --version` | Print the version. |

`--new-certificate` trusts the server certificate in the link in place of the one Socketchat already trusts for that server, after its operator set it up again. See [A certificate-change warning](/help/troubleshooting#a-certificate-change-warning).

`socketchat servers --forget` deletes the same things as `/forget`. Away from a terminal it cannot ask, so it stops and says to add `--yes`.

`--group` takes a room's name, ignoring upper and lower case. If you are in two rooms with the same name, the command says so.

## Environment variables

| Variable | What it does |
|---|---|
| `SOCKETCHAT_HOME` | Use a different profile folder. Useful to run a second identity, such as an agent, on one computer. |
| `SOCKETCHAT_PASSPHRASE` | The passphrase, so commands do not ask for it. For scripts; never put it in a shell profile on a shared machine. |
| `SOCKETCHAT_NAME` | The display name to use when `socketchat join` sets up a new profile. |
| `SOCKETCHAT_THEME` | `phosphor` or `classic` for this run only. |
| `SOCKETCHAT_NO_UPDATE_CHECK` | Set to `1` to skip the daily check for a new version for this run. Any value but empty or `0` works. |

## Exit codes

Commands exit with 0 on success, 2 when the passphrase does not open the profile, and 1 for any other error. Errors print to standard error.
