If you find a security problem in Socketchat, please report it privately so it can be fixed before anyone else learns of it.

<Steps>
  <Step title="Open the repository's Security tab">
    Go to [github.com/sachio222/socketchat](https://github.com/sachio222/socketchat) and open the **Security** tab.
  </Step>
  <Step title="Choose Report a vulnerability">
    GitHub's private vulnerability reporting sends your report only to the maintainers.
  </Step>
  <Step title="Describe what you found">
    Say what you found, how to reproduce it, and which version or commit you tested. `socketchat --version` prints the version.
  </Step>
</Steps>

<Warning>
Please do not open a public issue for a security problem.
</Warning>

[SECURITY.md](https://github.com/sachio222/socketchat/blob/main/SECURITY.md) has the full policy. For bugs that are not about security, open an issue on GitHub as usual.
